Konsep 1

Perulangan (Loop)

Perintah yang dilakukan berulang-ulang.
↻ repeat & forever

Contoh susunan blok yang benar

Ulangi 10 kali dipakai jika jumlah pengulangan sudah ditentukan. Selamanya dipakai jika perintah harus terus dijalankan sampai program dihentikan.
Jangan tertukar: perulangan dipakai untuk mengulang. Blok jika dan jika tidak termasuk percabangan karena memeriksa kondisi.

Coba langsung

Sentuh Repeat 10 dan Forever secara bergantian. Amati: kapan kucing berhenti?
Diskusikan: kapan kita memilih Repeat, dan kapan kita memilih Forever?
Konsep 2

Percabangan: “Jika–Maka” dan “Jika–Maka–Jika Tidak”

Percabangan membuat program memilih tindakan berdasarkan sebuah kondisi.
⑂ if & if–else
A. Jika ... Maka (IF)

Program memeriksa satu kondisi. Jika kondisi benar, aksi dijalankan. Jika kondisi salah, tidak ada aksi alternatif.

Contoh: Jika kucing menyentuh pinggir, maka kucing berputar 15 derajat. Jika belum menyentuh pinggir, tidak ada aksi tambahan.
B. Jika ... Maka ... Jika Tidak (IF–ELSE)

Program memilih dua kemungkinan: aksi untuk kondisi benar dan aksi lain untuk kondisi salah.

Ingat: Jika hanya memiliki aksi saat kondisi benar. Jika–Jika Tidak memiliki dua aksi: satu saat kondisi benar dan satu lagi saat kondisi salah.

Prediksi perilaku kucing

Apa yang akan dilakukan kucing ketika menyentuh pinggir?

Cek pemahaman cepat

Situasi: Jika nilai ≥ 75, tampilkan “Tuntas”. Jika tidak, tampilkan “Belajar lagi”.

Blok mana yang paling tepat?
Pilih jawaban, lalu jelaskan alasanmu.
Konsep 3

Operator

Hari ini fokus pada dua operator sederhana: penjumlahan (+) dan pembanding (=).
＋ dan =
+

Penjumlahan

Menghitung dua nilai. Contoh: 5 + 3 menghasilkan 8.

=

Pembanding

Memeriksa apakah dua nilai sama. Hasilnya benar atau salah.

Perhatikan: operator = dipakai untuk membandingkan apakah Jawaban sama dengan 8. Jika benar, program mengatakan Benar. Jika salah, program mengatakan Coba Lagi.

Coba operator secara langsung

Berapa hasil 5 + 3?
Program akan menghitung 5 + 3, kemudian membandingkan jawabanmu dengan hasil tersebut.
Pikirkan: operator + melakukan perhitungan. Operator = melakukan perbandingan.
Mini Proyek Kelompok

Tantangan: “Kucing Cerdas”

Ikuti urutan persis di bawah. Jangan menambah fitur sebelum program dasar berhasil.
👥 3–4 murid / Chromebook

Target akhir sangat jelas

Kucing bertanya soal 5 + 3, memberi respons benar/salah, kemudian bergerak terus dan bereaksi ketika menyentuh pinggir.

Langkah kerja — ikuti satu per satu

Buka Scratch dan gunakan sprite kucing.Jangan mengganti sprite dulu agar semua kelompok bekerja dengan target yang sama.
Pasang blok “ketika bendera hijau diklik”.Semua perintah dimulai dari blok ini.
Buat kucing bertanya: “Berapa hasil 5 + 3?”Gunakan blok ask ... and wait.
Periksa jawaban dengan IF–ELSE.Gunakan kondisi jawaban = (5 + 3). Jika benar, katakan “Benar!”. Jika tidak, katakan “Coba lagi!”.
Setelah memberi respons, buat kucing bergerak terus.Tambahkan forever lalu move 10 steps.
Di dalam forever, tambahkan kondisi pinggir.Jika menyentuh pinggir, gunakan if on edge, bounce atau perintah berbalik yang tersedia.
Tekan bendera hijau dan uji dua kali.Uji sekali dengan jawaban benar dan sekali dengan jawaban salah.
Jika belum berhasil, debugging.Periksa urutan blok. Ubah satu bagian saja, lalu uji kembali.

Program kalian harus memenuhi 6 cek ini

✓Kucing menanyakan 5 + 3.
✓Kondisi menggunakan operator + dan operator =.
✓Jawaban benar menghasilkan pesan “Benar!”.
✓Jawaban salah menghasilkan pesan “Coba lagi!”.
✓Kucing bergerak terus menggunakan forever.
✓Kucing bereaksi saat menyentuh pinggir.
Pembagian peran: operator menyusun blok, pembaca langkah membaca instruksi, pemeriksa kode mengecek urutan, dan penyaji menjelaskan hasil. Setelah ±8 menit, ganti operator.
Jika sudah berhasil lebih cepat: baru boleh mengganti angka 5 + 3 menjadi soal lain. Jangan menambah skor/level sebelum program inti benar.
